# LookAtJumAsm – Personal Resume Website 

**LookAtJumAsm** is a responsive personal resume/portfolio website built with HTML, CSS, and Bootstrap 5, developed as a Web Development course assignment at the University of Jeddah.

---

### About the Website
LookAtJumAsm was built to showcase my academic background, skills, and projects as a Software Engineering student in a clean, elegant, single-page format.

With the site, visitors can:
- Learn more through the **About** section
- View academic background in the **Education** section
- Browse featured projects: `Reads`, `Bookery`, `Darb`, and `Color Rush`
- Get in touch via the **Contact** section (phone, email, GitHub)

### Tech Stack
- **HTML5** – for page structure
- **CSS3** – for custom styling, hover effects, and scroll behavior
- **Bootstrap 5** – for the responsive navigation bar and collapse component
- **Google Fonts** – Marmalade, Mukta, and Twinkle Star for typography

---

### Responsive Design
The website was tested and verified across multiple breakpoints, including 576px, 768px, and 992px, ensuring a consistent experience on mobile, tablet, and desktop.

---

### HTML Validation
Passed the [Nu Html Checker (W3C)](https://validator.w3.org/nu/) with no errors or warnings.
